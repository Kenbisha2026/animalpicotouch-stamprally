NFC ANIMAL RALLY - GitHub Pages用

【GitHubにアップするファイル】
index.html

GitHubリポジトリの一番上（ルート）に index.html を置いてください。
フォルダごとアップロードする場合も、公開対象のルートに index.html がある状態にします。

GitHub Pages公開後の例：
https://ユーザー名.github.io/リポジトリ名/

NFCタグ用URL：
?stamp=owl
?stamp=hedgehog
?stamp=flamingo
?stamp=polarbear
?stamp=wolf

例：
https://ユーザー名.github.io/リポジトリ名/?stamp=owl

※ example.com はダミーURLなので使用しません。
