NFC ANIMAL RALLY - GitHub Pages用（5動物・専用URL版）

このフォルダ内の6つのHTMLを、GitHubリポジトリのルートにアップロードしてください。

index.html       : コレクション画面（開くだけでは取得しない）
owl.html         : フクロウ取得
hedgehog.html    : ハリネズミ取得
flamingo.html    : フラミンゴ取得
polarbear.html   : シロクマ取得
wolf.html        : オオカミ取得

どの順番で開いてもOKです。
未取得の動物ページを開くたびにコレクションが1つ増えます。
同じ動物は重複カウントしません。

重要:
・6ページすべて同じGitHub Pagesドメイン内なので、同じlocalStorageを共有します。
・同じスマホ/同じブラウザであれば順不同で蓄積します。
・シークレットモード、別ブラウザ、別端末では別コレクションになります。


【グッズ引き換え機能】
5匹コンプリート後、「🎁 グッズを引き換える」を押すと確認画面が表示されます。
スタッフの前で「引き換える」を押すと「✓ グッズ引き換え済み」に変わります。
引き換え状態は同じスマホ・同じブラウザのlocalStorageに保存されます。

※ブラウザのサイトデータ削除・別ブラウザ・別端末では状態を共有できません。
※展示用の簡易引き換え機能です。厳密な不正防止が必要な本番運用ではサーバー管理が必要です。


【15分後に次の周回を開始】
・5匹コンプリート時刻をブラウザに保存します。
・コンプリート後15分未満は、前回の5/5を維持します。
・コンプリート後15分以上たってから、どれかの動物URLを開くと、
  前回の5匹とグッズ引き換え状態を自動リセットします。
・そのとき開いた動物が、新しい周回の1匹目（1/5）になります。
・集める順番は自由です。
・index.html を開くだけではリセットしません。

例：
5/5コンプリート → 15分経過 → wolf.html
→ 自動リセット → オオカミ 1/5 から次の周回開始

※同じスマホ・同じブラウザ内で保存されます。
